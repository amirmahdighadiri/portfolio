## Features

- Responsive layout for desktop, tablet, and mobile.
- Persian and English language support.
- Automatic RTL/LTR direction based on the selected language.
- Light and dark themes.
- Language and theme preferences saved in local storage.
- Animated section reveals and interactive UI details.
- Project cards with live-demo and GitHub links.
- Reusable React components and a modular project structure.

## Tech Stack

- **React 19** — UI development.
- **JavaScript (ES6+)** — application logic.
- **Vite 8** — development server and build tooling.
- **Tailwind CSS 4** — styling.
- **Motion** — UI animations.
- **Context API** — shared language and theme state.

## Getting Started

### Prerequisites

- Node.js (a current LTS version is recommended).
- npm.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/amirmahdighadiri/portfolio.git
   ```

2. Open the project directory:

   ```bash
   cd portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Create a production build:

   ```bash
   npm run build
   ```
